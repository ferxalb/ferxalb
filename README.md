## 🧰 Projects

### Developer tools & agents
- **[Rainy Updates](https://github.com/ferxalbs/rainy-updates)**: deterministic dependency checks, risk prediction and upgrades for Node monorepos. Outputs JSON, SARIF and PR reports. [Docs](https://ferxalbs.github.io/rainy-updates/)
- **[AETHER Midnight](https://github.com/ferxalbs/aether-midnight)**: local code search and explicit memory for AI agents. Offline keyword search, optional semantic search.
- **[AETHER Fx](https://github.com/ferxalbs/aether-fx)**: experimental native terminal coding agent in a single Rust binary.

### Apps
- **[AETHER Dots](https://github.com/ferxalbs/aether-dots)**: native macOS app for AI teammates with their own memory and permissions.

### Experiments
- **[AETHER Fx Lang](https://github.com/ferxalbs/aether-fx-lang)**: a declarative language for 2D animation that plays on Canvas and exports to video.
- **[Vuelta](https://github.com/ferxalbs/aether-vuelta)**: rehearses backup recovery in a throwaway workspace and records the evidence.
- **[rainy-sdk-ts](https://github.com/ferxalbs/rainy-sdk-ts)**: TypeScript SDK for the Rainy API.

> Most projects are in **alpha or beta**. Check each repo's README for its current status and supported platforms before relying on it.
